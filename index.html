    How VLC works on each device

    • Phone / tablet (Android, iPhone, iPad): install the free VLC app. Tapping a track opens it straight in VLC.
    • Chromecast with Google TV / Android TV / Fire TV: install VLC from the store, then install the DJSinatra TV app (APK).
    • PC / Mac: tapping a track downloads a small .m3u playlist — open it and VLC streams the song.
    • Any TV with VLC (Apple TV, smart TVs): use Copy link, then in VLC choose Network → Open Network Stream and paste.
